# Instagram 帖子数据集样本

<h2>包含 7,730 条记录的数据集样本</h2>

<a href="https://www.bright.cn/">

此 **Instagram 帖子数据集样本**包含 **7,730 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名 | 说明 |
|------------|-------------|
| `url` | Instagram 帖子的直接链接。 |
| `user_posted` | 发布该内容的账号用户名。 |
| `description` | Instagram 帖子的配文。 |
| `hashtags` | 帖子中使用的话题标签列表，有助于发现相关内容。 |
| `num_comments` | 帖子的评论总数。 |
| `date_posted` | 帖子发布的时间戳。 |
| `likes` | 帖子获得的点赞数。 |
| `photos` | 帖子中图片的 URL。 |
| `videos` | 帖子中视频的 URL。 |
| `location` | 帖子标记的地理位置。 |
| `latest_comments` | 帖子近期收到的评论。 |
| `post_id` | Instagram 帖子的唯一标识符。 |
| `discovery_input` | 用于发现该帖子的关键词或其他输入条件。 |
| `has_handshake` | 表示帖子是否属于品牌内容合作。 |
| `shortcode` | 用于帖子 URL 的简短唯一代码。 |
| `content_type` | 帖子的内容形式，例如图片、视频或轮播帖。 |
| `pk` | 用于内部数据处理的主键标识符。 |
| `content_id` | 系统为内容生成的 ID。 |
| `engagement_score_view` | 反映帖子互动情况的计算指标。 |
| `thumbnail` | 帖子缩略图的 URL。 |
| `video_view_count` | 视频的观看次数。 |
| `product_type` | 帖子的分类，例如普通内容或品牌内容。 |
| `coauthor_producers` | 与帖子相关的共同作者或制作人的用户名。 |
| `tagged_users` | 帖子中标记的用户列表。 |
| `video_play_count` | 视频的播放次数。 |
| `followers` | 发帖账号的粉丝数。 |
| `posts_count` | 该用户发布的帖子总数。 |
| `profile_image_link` | 用户头像的 URL。 |
| `is_verified` | 表示用户账号是否已获得 Instagram 认证。 |
| `is_paid_partnership` | 表示帖子是否属于付费合作。 |
| `partnership_details` | 品牌合作或其他合作的详细信息。 |
| `user_posted_id` | 内容发布者的唯一标识符。 |
| `post_content` | 帖子的主要内容，包括文字和媒体。 |
| `audio` | 帖子所用音频的详细信息。 |
| `profile_url` | 用户 Instagram 个人主页的 URL。 |
| `videos_duration` | 帖子中视频内容的时长。 |
| `images` | 与帖子相关的图片数组。 |
| `alt_text` | 帖子图片的替代文本描述。 |
| `photos_number` | 帖子包含的图片数量。 |
| `audio_url` | 帖子所用音频的链接。 |

## 使用场景

### 1. 社交媒体趋势分析
分析帖子的互动指标，识别 Instagram 上的热门内容和用户偏好。

### 2. 网红营销策略
利用用户和互动数据，为品牌合作筛选具有影响力的创作者。

### 3. 竞品分析
监测竞品的互动表现和内容策略，优化自身的社交媒体运营方式。

# Instagram 帖子数据集样本

<h2>包含 7,730 条记录的样本数据集</h2>

<a href="https://www.bright.cn/">
    <img src="https://github.com/bright-cn/Instagram-Posts-dataset-samples/blob/main/datasets-image.png" alt="Bright Data 数据集" />

此 **Instagram 帖子数据集样本**包含 **7,730 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Instagram 帖子的直接链接。 |
| `user_posted` | 发布该内容的账号用户名。 |
| `description` | Instagram 帖子随附的说明文字。 |
| `hashtags` | 帖子中使用的主题标签列表，有助于发现内容。 |
| `num_comments` | 帖子的评论总数。 |
| `date_posted` | 帖子发布时的时间戳。 |
| `likes` | 帖子获得的点赞数。 |
| `photos` | 帖子中所含照片的 URL。 |
| `videos` | 帖子中所含视频的 URL。 |
| `location` | 帖子中标记的地理位置。 |
| `latest_comments` | 帖子近期收到的评论。 |
| `post_id` | Instagram 帖子的唯一标识符。 |
| `discovery_input` | 用于发现该帖子的关键词或输入内容。 |
| `has_handshake` | 指示该帖子是否属于品牌内容合作的一部分。 |
| `shortcode` | 帖子 URL 的唯一短代码。 |
| `content_type` | 帖子的格式，例如照片、视频或轮播帖子。 |
| `pk` | 用于内部数据处理的主键标识符。 |
| `content_id` | 系统为内容生成的 ID。 |
| `engagement_score_view` | 表示帖子互动情况的计算指标。 |
| `thumbnail` | 帖子缩略图的 URL。 |
| `video_view_count` | 视频的观看次数。 |
| `product_type` | 帖子的分类，例如标准内容或品牌内容。 |
| `coauthor_producers` | 与帖子相关的共同创作者或制作人的用户名。 |
| `tagged_users` | 帖子中标记的用户列表。 |
| `video_play_count` | 视频的播放次数。 |
| `followers` | 发帖账号的粉丝数。 |
| `posts_count` | 用户发布的帖子总数。 |
| `profile_image_link` | 用户头像的 URL。 |
| `is_verified` | 指示用户账号是否已通过 Instagram 验证。 |
| `is_paid_partnership` | 指示该帖子是否为付费合作内容。 |
| `partnership_details` | 合作或协作的详细信息。 |
| `user_posted_id` | 发布该内容的用户的唯一标识符。 |
| `post_content` | 帖子的主要内容，包括文本和媒体。 |
| `audio` | 帖子中所用音频的详细信息。 |
| `profile_url` | 用户 Instagram 个人资料页的 URL。 |
| `videos_duration` | 帖子中视频内容的时长。 |
| `images` | 与帖子相关的图片数组。 |
| `alt_text` | 帖子图片的替代文本描述。 |
| `photos_number` | 帖子中包含的照片数量。 |
| `audio_url` | 帖子中所用音频的链接。 |


## 使用场景

### 1. 社交媒体趋势分析
分析帖子互动指标，以识别 Instagram 上的热门内容和用户偏好。

### 2. 网红营销策略
利用用户和互动数据，为品牌合作选择最具影响力的网红。

### 3. 竞争分析
监测竞争对手的互动情况和内容策略，以优化你自己的社交媒体方案。
